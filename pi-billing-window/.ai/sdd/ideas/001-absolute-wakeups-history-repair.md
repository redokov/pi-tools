# Idea: Абсолютные контрольные точки пробуждения + ремонт history CSV

> Status: direction confirmed
> Created: 2026-10-24
> Source: запрос пользователя (сессия pi, 2026-10-24)

## Raw Idea

1. Основной тик — двухчасовой, привязанный к **абсолютным** моментам времени
   (крон-подобная таблица пробуждений), а не к плавающему `setInterval(5мин)`.
   `/settimer 76` в 9:00 → refresh ≈ 10:16 → контрольные точки: 10:18, 12:18,
   14:18, 16:18 … (маржа +2 мин). Если «продолжи» не запускает процесс (лимит
   не обновился) — малые 5-минутные ретраи дожимают запуск и корректируют
   следующую точку.
2. Избавиться от warning'а `unrecognized history header` — history CSV
   начинается с 5.8 МБ NUL-байтов, заголовок затёрт.

## Problem Space

- **Problem:** постоянный 5-минутный тикер дрейфует/пропускает тики →
  `billing:window_reset` наступает с опозданием на часы → взведённые
  cont-after-reset окна ждут, пользователь вручную пишет «продолжи».
- **Who:** пользователь, запускающий ночные прогоны (APKScenTest) на wormsoft.
- **When:** ночные прогоны; дырки в history 8–12 ч (напр. 23.10 09:03→21:38).
- **Workaround:** ручное `/settimer` + ручное «продолжи».

## Desired Outcome

Reset окна срабатывает в заранее вычисленную абсолютную точку wall-clock;
«продолжи» уходит только в остановленные взведённые чаты без участия человека.

## Signals of Value

- history: `window_reset` в точках таблицы ± минуты, без ручных вмешательств;
- ночные прогоны продолжаются без ручного «продолжи».

## Constraints

| Constraint | Notes |
|---|---|
| Технология | pi extension (TS), общий state-файл между окнами pi |
| Сон машины | ВНЕ области: пользователь вручную `/settimer` после включения |
| Провайдер | окно плавающее: 2ч отсчитываются от ПЕРВОГО расхода кредитов после refresh |

## Possible Directions

- **A. Внутренние абсолютные таймеры** (выбрано): таблица пробуждений в общем
  файле + самокорректирующийся `setTimeout(deadline−now)` + страховка 60-сек
  sync-poller. Просто, без внешних зависимостей.
- **B. Внешний schtasks wake-to-run**: надёжнее при сне машины — отклонено
  (машина гарантированно не спит в ночные прогоны; сон = вне области).
- **C. Якорь на фиксированный wall-clock график провайдера**: отклонено —
  график плавающий (от первого расхода кредитов).

## Resolved Questions (контекст для requirements)

- Окно wormsoft плавающее: следующая точка = `firstCallAt + 2ч + маржа`.
- Таблица: `~/.pi/agent/pi-billing-window-wakeups.json`, глубина 12 записей,
  маржа +2 мин, самовозобновляемая; перезаписывается `/settimer`,
  `/billing-reset`, каждым авто-ресетом; инициализация автоматическая.
- «продолжи» — только в остановленные взведённые чаты (уже реализовано:
  `isIdle` + `ownerQuiet` + firelease, index.ts:1515+).
- 5-мин ретраи после неудачного «продолжи» — уже реализованы
  (`RETRY_AFTER_FIRE_MS`, pending-фаза).
- CSV: разовый ремонт (срезать NUL-блок, восстановить 13-колоночный заголовок
  с BOM, данные с 2026-10-14 сохранить) + авто-починка NUL-префикса в
  `ensureSchemaLocked` молча.
